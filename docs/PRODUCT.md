# &lt;notes&gt; — продукт

> Рабочее название. Живой документ: дополняем по мере обсуждения.
> Как это устроено внутри — в [CONTEXT.md](CONTEXT.md).

## Суть

Нативное macOS-приложение для заметок. Заметки — обычные Markdown-файлы в локальной
папке. Синхронизация идёт автоматически через git-репозиторий. Есть поиск по смыслу, голосовая
надиктовка на открытой локальной модели и задачи, которые попадают в Apple Calendar.

## Для кого

В первую очередь для автора: делается для себя. Проект open source, кому нужно, тот пользуется.

## Принципы

- **Делаем хорошо, а не тяп-ляп.** Лучше меньше функций, но каждая доведена до конца.
- **Local-first.** Все данные лежат локально, в обычных `.md` файлах. Никаких аккаунтов, регистраций и своего сервера.
- **Файлы — источник правды.** Хранилище открывается в любом другом редакторе, и ничего не ломается.
- **Лёгкое приложение.** Сама программа маленькая. Тяжёлое (модели) не входит в сборку: скачивается по требованию, и только то, что включено.
- **Только macOS.** iOS, iPadOS и visionOS не делаем.
- **Open source.** Модели и библиотеки тоже открытые.
- **Дизайн делает автор.**

## Функции

### 1. Markdown-заметки (ядро)
- Хранилище (vault) — это папка на диске, которую выбирает пользователь.
- Дерево папок и файлов, создание, переименование и удаление заметок.
- **Папки — карточки** в форме папки с «наклейкой»: название крупно, белым с цветной обводкой, с наклоном.
  Цвет папки выбирает пользователь. Экран «все заметки» — сетка папок и список заметок без папки.
- Редактор Markdown (вид — по дизайну).

### 2. Git в папке и GitHub
- Приложение **инициализирует git-репозиторий в папке хранилища** (`git init`), и каждая правка сама
  коммитится: появляется история версий, любую заметку можно откатить.
- Чтобы история попадала на GitHub, нужен вход. Своего сервера у автора нет, поэтому только GitHub:
  1. «войти через github»: приложение показывает короткий код, пользователь вводит его на
     github.com/login/device и подтверждает. Пароль в приложение не вводится.
  2. Приложение **само создаёт приватный репозиторий `notes`** и отправляет туда историю (push).
     Если `notes` уже есть, подключается к нему.
  3. Дальше история отправляется на GitHub сама, раз в день.
- Вход можно пропустить, тогда история остаётся только на этом Mac.
- Приложение само никуда не лезет: ни в `~/.ssh`, ни в глобальные настройки git. Токен GitHub хранится в Keychain.
- Если папка уже была репозиторием (например, заметки уже вели в git), `git init` не делаем.
- Свой SSH-ключ и другие серверы (GitLab и т.п.) пока не делаем.

### 3. Поиск по смыслу
- Заметки индексируются векторной моделью (эмбеддинги), и искать можно по смыслу, а не только по словам.
- Индексация в фоне, после изменений — только изменившиеся файлы.
- Индекс — кэш вне хранилища: его можно удалить и пересобрать, в git он не попадает.
- Модель лёгкая, работает локально и нормально понимает русский.
- Обычный поиск по тексту тоже есть.

### 4. Голосовая надиктовка
- Локальное распознавание речи на открытой модели (Whisper). Работает офлайн.
- Глобальная горячая клавиша, которую пользователь назначает сам. Работает **из любого приложения**.
- По нажатию поверх всех окон появляется стеклянная сфера, как у Siri, а внутри неё чёрно-белые
  светящиеся волны от голоса. Форма — круг (есть запасной вариант: скруглённый пятиугольник).
  Три состояния: слушает → распознаёт (волны схлопываются в линию) → галочка «скопировано».
  Больше ничего на экране нет, без кнопок и подписей.
- **Распознанный текст копируется в буфер обмена.** Вставляет пользователь сам, куда хочет.

### 5. Задачи и Apple Calendar
- Задачи с датой и временем создаются в приложении. Список задач: сегодня / завтра / без даты.
- Задачи синхронизируются с Apple Calendar (EventKit, события календаря).
- **Экран календаря** (день / неделя / месяц): задачи из заметок видны вместе с событиями из других календарей.
  Задачи выделены обводкой и отметкой, события — заливкой цвета их календаря.
- Сами задачи хранятся в Markdown, чтобы не нарушать принцип «файлы — источник правды».

### 6. Расшифровка видео
- Загружаешь видео, приложение расшифровывает речь локально (та же модель, что для надиктовки) и делает из этого заметку.
- Экран: список уже расшифрованных видео и загрузка нового с прогрессом.
- Технические детали и сама идея — автор расскажет отдельно.

### 7. Первый запуск (онбординг)
Шаги, ветки и анимации — в [ONBOARDING.md](ONBOARDING.md): загрузка → папка → git → GitHub (по желанию)
→ модель распознавания → разрешения → пароль → «всё готово».

Макет всех экранов — Figma, ссылка в CLAUDE.md.

## Чего не делаем

- **Канбан.** Решено: не нужен.
- Версии для iPhone, iPad и Vision Pro.
- Аккаунты, свой сервер и облако.
