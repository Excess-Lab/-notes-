# Roadmap

Черновой порядок работ. Каждый этап даёт что-то рабочее и проверенное.

## 0. Подготовка проекта
- [x] Оставить в Xcode-проекте только macOS (сейчас шаблон мультиплатформенный: iOS / macOS / visionOS).
- [ ] Выбрать название и нормальный bundle identifier.
- [x] `.gitignore` для Xcode (`xcuserdata/` и т.п.)
- [ ] Лицензия, README.
- [x] Каркас тестов (Swift Testing, пакет NotesCore).

## 1. Заметки
- [x] Выбор папки-хранилища (песочница, security-scoped bookmarks).
- [ ] Сайдбар с деревом файлов и редактор Markdown.
- [ ] Отслеживание изменений, сделанных снаружи.

## 2. Git в папке и GitHub
- [x] `git init` в папке хранилища (если репозитория ещё нет), `.gitignore`, первый коммит.
- [x] Автокоммит изменений в фоне (раз в час, подпись по заметкам).
- [ ] История версий заметки и откат.
- [x] Вход в GitHub по коду (Device Flow), токен в Keychain. Нужен client id (GitHubApp.swift).
- [x] Создание приватного `notes` и первый push.
- [x] Push раз в день.
- [ ] Pull (правки с другого Мака) и конфликты без потери текста.
