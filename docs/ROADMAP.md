# Roadmap

Черновой порядок работ. Каждый этап даёт что-то рабочее и проверенное.

## 0. Подготовка проекта
- [ ] Оставить в Xcode-проекте только macOS (сейчас шаблон мультиплатформенный: iOS / macOS / visionOS).
- [ ] Выбрать название и нормальный bundle identifier.
- [ ] `.gitignore` для Xcode (`xcuserdata/` и т.п.), лицензия, README.
- [ ] Каркас тестов (Swift Testing).

## 1. Заметки
- [ ] Выбор папки-хранилища (песочница, security-scoped bookmarks).
- [ ] Сайдбар с деревом файлов и редактор Markdown.
- [ ] Отслеживание изменений, сделанных снаружи.

## 2. Git в папке и GitHub
- [ ] `git init` в папке хранилища (если репозитория ещё нет), `.gitignore`, первый коммит.
- [ ] Автокоммит изменений в фоне.
- [ ] История версий заметки и откат.
- [ ] Вход в GitHub по коду (Device Flow), токен в Keychain.
- [ ] Создание приватного `notes`, push/pull, конфликты без потери текста.

## 3. Надиктовка
- [ ] Локальный Whisper и загрузка модели по требованию.
- [ ] Глобальный хоткей с настройкой.
- [ ] Плавающий оверлей с анимацией записи.
- [ ] Результат — в буфер обмена.

## 4. Поиск
- [ ] Обычный поиск по тексту.
- [ ] Эмбеддинги и фоновая инкрементальная индексация.
- [ ] Поиск по смыслу.

## 5. Расшифровка видео
- [ ] Детали — после разговора с автором.

## 6. Задачи и календарь
- [ ] Формат задач в Markdown.
- [ ] Синхронизация с Apple Calendar через EventKit.

## Потом
- [ ] Тёмная тема. Сейчас приложение принудительно светлое (`.preferredColorScheme(.light)` в `MyApp.swift`):
      в тёмной теме системное стекло и заголовок темнеют, а макеты есть только светлые.
