# Первый вход: флоу и анимации

Макеты лежат в Figma, в секциях «Загрузка» и «первый вход». Номера в скобках — номера кадров
в названиях фреймов, их проставил автор. Окно 560×440.

Общее правило движения: всё плавное, в духе iPhone (spring-анимации, без резких переходов).
Каждый переход между шагами анимированный.

---

## 0. Загрузка (кадр «Загрузка»)

Сцена при открытии приложения.

- **Стеклянные планки растут в ширину.** Расстояние между ними всегда ноль: зазор не растёт,
  увеличивается ширина каждой планки, плавно.
- **Логотип `<notes>` проявляется** мягко, как появление в стиле Apple (fade + лёгкий scale).
- Когда всё загрузилось:
  1. логотип **уменьшается и уезжает вверх**, на своё место в шапке;
  2. снизу **выезжает белый лист** с контентом шага 1, текст выезжает вместе с ним.

## 1. Привет (кадр «Первый вход(1)»)

- «создать папку» — открывается Finder (системное окно сохранения), пользователь создаёт папку.
- «выбрать папку» — открывается Finder (окно выбора папки).
- После выбора → шаг 2.

## 2. Git в папке (кадр «Настройка гита(2)»)

- «инициализировать» — `git init` в папке → шаг 3.
- «пропустить, настрою потом» — git не делаем, и GitHub тоже не предлагаем → **сразу шаг 6**.

## 3. Отправлять на GitHub? (кадр «гитхаб(3)»)

- «войти через github» → шаг 4.
- «нет, только на этом маке» — история остаётся локальной → **сразу шаг 6**.

## 4. Код GitHub (кадр «код гитхаба(4)»)

- Код в капсуле. **Обводка капсулы пульсирует** (цвет — оранжевый, точный цвет автор пришлёт).
- «скопировать код» под кодом; «открыть github» — копирует код и открывает github.com/login/device.
- «назад» — шаг 3, опрос GitHub останавливается и `device_code` забывается (см. CONTEXT.md).
- Код живёт 15 минут. Подтвердили на GitHub → шаг 5.

## 5. GitHub подключён (кадр «гитхаб кул (5)»)

- «готово!», создан приватный `notes`, история отправляется туда раз в день. «дальше» → шаг 6.

## 6. Модели (кадр «модели (6)»)

- Список моделей распознавания. **По умолчанию выбрана GigaAM v3** — она ярче остальных.
- Остальные (Whisper small, Whisper large-v3 turbo) можно выбрать, выбор переключается плавно.
- «дальше» → шаг 7.

## 7. Скачивание модели (кадр «модели скачивание(7)»)

- Прогресс скачивания выбранной модели. «дальше» не ждёт конца скачивания (качается в фоне).
- Скачивание настоящее (NotesSpeech.ModelStore): прогресс и оценка времени по уже скачанному.

## 8. Разрешения (кадр «разрешения(8)»)

- Микрофон, календарь, горячая клавиша. «дальше» → шаг 9.

## 9. Пароль (кадр «пароль(9)»)

- «установим пароль?»: **пинкод (4 символа)** или **pass-key**, у каждого «настроить».
- «настроить» у пинкода — **поверх появляется окно ввода** (кадры 9.1–9.3, дизайн согласован):
  шаг под ним размыт, «отмена» сверху карточки, четыре ячейки. Кнопки «готово» нет — четвёртая цифра
  ведёт дальше: «придумай пинкод» → «повтори пинкод» → строка «включено». Не совпало — ячейки
  качаются и обводятся коралловым, «не совпало / придумай заново». Текущая ячейка — с коралловой
  внутренней тенью. Esc — отмена, delete стирает цифру.
- Сделано: пинкод в Связке ключей как PBKDF2-хеш с солью (`NotesCore/PinCode.swift`).
- **Вход при повторном запуске** (секция «вход», кадры 11 и 11.1): первый вход пройден и есть пинкод
  или Touch ID — та же анимация загрузки, логотип уезжает в шапку, лист выезжает с «введи пинкод»
  и четырьмя ячейками. Включён Touch ID — система сразу спрашивает отпечаток, клик по листу —
  спросить снова. Неверный пинкод — «неверный пинкод» коралловым, ячейки качаются и пустеют.
  После входа лист пока пустой: основного экрана нет.
- **Умный вход** (`NotesCore/LockPolicy.swift`, `Vault/AppLock.swift`):
  - пинкод не спрашиваем, если приложение закрыли меньше 5 минут назад и Mac с тех пор не блокировался;
  - Mac заблокировали или он уснул — заметки закрываются сразу;
  - приложение пробыло в фоне 15 минут — спрашиваем при возврате;
  - окно Touch ID появляется, только когда приложение впереди;
  - 5 ошибок без паузы, потом «много попыток — подожди 30 с» (кадр 11.2), дальше вдвое дольше, максимум
    15 минут; пауза переживает перезапуск;
  - «забыл пинкод» — мелкая серая ссылка внизу: пароль от Mac или Touch ID, потом новый пинкод;
  - надиктовка от входа не зависит: заметок она не показывает.
- **Открытый вопрос:** что именно защищает пароль.
  Если шифровать сами заметки, их не откроет ни один другой редактор — это ломает принцип
  «файлы — источник правды». Поэтому, скорее всего, пароль закрывает только вход в приложение,
  а сам ключ хранится в Keychain. Pass-key на Mac — это Touch ID (LocalAuthentication).

## 10. Всё готово (кадр «все круто!(10)»)

- На последнем шаге нажали «дальше»: **логотип улетает**, всё содержимое уходит вниз,
  и «всё готово» **проявляется из стекла** на фоне планок. Подпись «листай вниз».
- Пользователь листает вниз → переход на основной экран (его ещё не рисовали).
