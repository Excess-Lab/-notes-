# Порт под Windows

Для сессии, которая переносит `<notes>` на Windows. Прочитай целиком до первой правки, вместе с
[CLAUDE.md](../CLAUDE.md), [MAKAR.md](MAKAR.md), [DECISIONS.md](DECISIONS.md) и [CONTEXT.md](CONTEXT.md).
Все запреты из CLAUDE.md действуют и здесь: без своего сервера, без базы с текстом, без пуша,
без новых зависимостей и своего интерфейса без слова Макара, никаких упоминаний Obsidian.

## Цель

Приложение под Windows, которое открывает **то же хранилище**, что и версия для Mac, и не портит его.
Мак и Windows могут работать с одной папкой через git одновременно. Формат хранилища — общий
договор: всё, что Windows пишет в папку, должно читаться маком без потерь, и наоборот.

## Где работать (иначе сломаешь чужую работу)

- **На маке рядом с мак-сессией**: у неё в основной папке незакоммиченные правки. Не работай там,
  возьми ветку в свой worktree: `git fetch origin && git worktree add ../notes-windows Dev-Windows`.
- **На Windows или в облаке**: свой клон, `git checkout Dev-Windows`. Папку клонировать как `notes`,
  не `<notes>`: такое имя Windows не примет.
- Код порта — только в папке `desktop/` в корне репозитория (не `windows/`: потом там же будет мак). Мак-код (`<notes>/`, `NotesSpeech/`,
  `NotesCore/`, `Scripts/`, `<notes>.xcodeproj`) не трогать. Нужна правка в общем коде — спроси Макара.
- Коммиты — в ветку `Dev-Windows`, модуль `Windows`: `Feature Windows / Add vault picker`.
  Ничего не сливать в `Dev` и `main` и не пушить без слова Макара.
- Задачи порта — в разделе «Задачи» ниже, что сделано — в «Журнале». TASKS.md — журнал мак-версии,
  его здесь не правим: так ветки не конфликтуют. Даты в журнале — в формате `2026-11-01`.

## Стек и план

**Tauri 2** (решение 2026-11-01, [DECISIONS.md](DECISIONS.md)): логика на Rust, интерфейс — HTML/CSS/TS.
Мак пока остаётся на Swift. Windows — проверка Tauri: как он себя ведёт и как выходит кастомное
стекло. Если проверка удалась — на тот же код переезжает мак, Swift-версия уходит в архив.
Макару важен вид из его фреймов Figma, плавные анимации и стеклянные слои ([UI.md](UI.md)).
Экраны рисует он: мак-версия — образец, но новый экран или элемент без его фрейма не придумывать.

## Архитектура (сразу под две ОС)

```
desktop/
├── src/              интерфейс: HTML/CSS/TS, общий для Windows и мака
└── src-tauri/        Rust
    ├── core/         хранилище, задачи, git, синхронизация, поиск, шаблоны — без ОС
    └── platform/     системное: секреты, вход по лицу/пальцу, хоткей, вставка, календарь
        ├── windows   Credential Manager, Windows Hello, RegisterHotKey, UI Automation
        └── macos     Связка ключей, Touch ID, Carbon, EventKit — пишется при переезде мака
```

- Общий Rust-код не знает про ОС. Всё системное — трейт в `platform/` и реализация за `#[cfg(target_os)]`.
  На маке сначала заглушки, чтобы проект собирался на обеих ОС с первого дня.
- Интерфейс одинаковый на обеих ОС. Стекло: окно — `tauri-plugin-liquid-glass` на маке (системный
  Liquid Glass, приватный API) и Mica/Acrylic на Windows; капсулы внутри окна — WebGL-стекло,
  одно на обе ОС. Библиотеку выбрать проверкой; на маке движок — WebKit, CSS-искажение в
  `backdrop-filter` там не работает.
- Поведение — по тестам `NotesCore/Tests`: каждый тест переносится в Rust до удаления Swift-кода.
- Хранилище — тот же договор, что ниже: Swift-мак и Tauri-Windows работают с одной папкой.
- Сборка обеих ОС — в CI (GitHub Actions, раннеры windows и macos), раз облачная сессия на Linux
  их не соберёт.

## Что переносится и чем заменить

| На Mac | Что делает | На Windows |
|---|---|---|
| `NotesCore` (Foundation, libgit2) | заметки, задачи, git, синхронизация, шаблоны | логика переписывается на Rust (`desktop/src-tauri/core`); тесты `NotesCore/Tests` — образец поведения |
| libgit2 | git без установленного git | libgit2 через крейт `git2` |
| Keychain (`TokenStore`, `PinCode`) | токен GitHub, хеш пинкода | Windows Credential Manager / DPAPI. Не в файлах и не в реестре открытым текстом |
| LocalAuthentication | Touch ID | Windows Hello |
| Carbon hotkey | глобальная надиктовка | `RegisterHotKey` |
| AX + CGEvent ⌘V | вставка в поле с курсором | UI Automation + `SendInput` Ctrl+V, только если фокус в текстовом поле |
| EventKit | задачи в Apple Calendar | **решение Макара**: Apple Calendar на Windows нет |
| FoundationModels | «кратко» и задачи из расшифровки | аналога нет. Скрыть функцию и спросить Макара |
| NaturalLanguage (`SemanticIndex`) | поиск по смыслу | нужна замена-модель: спросить, качать только по требованию |
| WhisperKit (CoreML) | распознавание Whisper | whisper.cpp или sherpa-onnx |
| sherpa-onnx (GigaAM, спикеры) | распознавание, кто говорит | sherpa-onnx есть под Windows. Те же модели, ссылки и SHA |
| Metal (`Orb.metal`, `DropZone.metal`) | сфера надиктовки, зона перетаскивания | портировать шейдер (HLSL/Direct2D) по виду с мака |
| FSEvents (`FolderWatcher`) | правки снаружи | `ReadDirectoryChangesW` / `FileSystemWatcher` |
| ServiceManagement | запуск при входе | ключ `Run` текущего пользователя |
| `~/Library/Application Support/<id>/` | модели, индекс, кэш | `%LOCALAPPDATA%\notes\`. В хранилище ничего не класть |

## Формат хранилища (договор с маком)

Подробно — [CONTEXT.md](CONTEXT.md). Самое важное:

- Заметка — обычный `.md`, папки — обычные папки. Свои служебные файлы в хранилище не создавать.
- Задача: `- [ ] текст 📅 yyyy-MM-dd` или `… 📅 yyyy-MM-dd HH:mm`, отметка — `- [x]`.
- Расшифровки — в папке `расшифровки/`, шаблоны — в папке шаблонов из настроек. Плейсхолдеры:
  `{{дата}}`, `{{время}}`, `{{название}}`.
- При конфликте git сохраняются обе версии, ничего не выбрасывается молча.

## Грабли, которых на маке нет

- **Нормализация Юникода.** Мак пишет имена файлов в NFD, Windows — в NFC. «й» и «ё» становятся
  разными строками: дубли файлов, «удалённые» заметки в git. Сравнивай пути после нормализации
  и не переименовывай чужие файлы ради неё.
- **Запрещённые имена.** На Windows нельзя `< > : " / \ | ? *`, имена `CON`, `NUL`, `COM1` и т. п.,
  точку или пробел в конце. С мака такие заметки придут. Не падать, не переименовывать молча:
  показать человеку, какие файлы не открылись.
- **Название `<notes>`** нельзя использовать как имя папки или файла на Windows. Для путей бери `notes`.
- **Перевод строк.** Не превращать LF в CRLF: в репозитории хранилища ставить `core.autocrlf=false`
  локально (только в нём; глобальный конфиг git не трогать). Сохранять файл с теми концами строк,
  с какими он пришёл.
- **Длинные пути** (больше 260 символов) и регистр букв в имени (обе системы его не различают,
  а git различает).
- Кириллица в путях везде: в тестах, логах, путях моделей.

## Проверка

Сделано — значит проверено на Windows: сборка, тесты, снимок окна рядом с кадром мака или Figma.
Если сессия идёт на маке и собрать или запустить под Windows нельзя — так и сказать Макару,
а не «должно работать». Хранилище для проверок — тестовое, не его настоящее.

- [готово] **Стек выбран** (2026-11-01): Tauri на Windows как проверка, мак потом тоже на Tauri
  («на маке оставляем свифт на винде тестим таури… сразу учти и планируй что мы и на маке потом будем
  тоже таури юзать»). Kotlin, C# отпали. Ход обсуждения:
  - C# — нет: «мне не нравится сишарп». SwiftUI на Windows не бывает, перегнать его автоматически нечем
    (SwiftCrossUI — эксперимент, Skip — только Android).
  - Бэк на Rust — Макар «склоняется очень сильно».
  - **Tauri везде** (Rust + один веб-интерфейс на обе ОС): дёшево, дизайн кастомный. Минус — Liquid Glass
    на маке не 1:1 (~85 %: размытие, блики, преломление своего контента через WebGL; живого преломления
    того, что за окном, нет).
  - **Rust-ядро + SwiftUI на маке + Tauri на Windows**: Liquid Glass 100 %, но экраны верстаются дважды.
  - Склоняется (последнее слово): «делаю под мак и потом из-под мака под винду это всё переделывается» —
    мак первый, Windows догоняет порциями; часто менять приложение не планирует. Пугает цена двух
    интерфейсов. Ещё вариант от него — Kotlin под Windows и Swift под мак.
  - Предложено: демо-страница стекла на CSS + WebGL, открыть в Safari и сравнить с маком.
