# Порт под Windows

Для сессии, которая переносит `<notes>` на Windows. Прочитай целиком до первой правки, вместе с
[CLAUDE.md](../CLAUDE.md), [MAKAR.md](MAKAR.md), [DECISIONS.md](DECISIONS.md) и [CONTEXT.md](CONTEXT.md).
Все запреты из CLAUDE.md действуют и здесь: без своего сервера, без базы с текстом, без пуша,
без новых зависимостей и своего интерфейса без слова Макара, никаких упоминаний Obsidian.

## Цель

Приложение под Windows, которое открывает **то же хранилище**, что и версия для Mac, и не портит его.
Мак и Windows могут работать с одной папкой через git одновременно. Формат хранилища — общий
договор: всё, что Windows пишет в папку, должно читаться маком без потерь, и наоборот.

## Где работать (иначе сломаешь чужую работу)

- В этой же папке параллельно работает сессия под Mac, и у неё в дереве незакоммиченные правки.
  **Не работай в основной папке.** Сделай свой worktree и ветку от `Dev`:
  `git worktree add ../notes-windows -b Windows Dev`.
- Код порта — только в папке `windows/` в корне репозитория. Мак-код (`<notes>/`, `NotesSpeech/`,
  `NotesCore/`, `Scripts/`, `<notes>.xcodeproj`) не трогать. Нужна правка в общем коде — спроси Макара.
- Коммиты — в ветку `Windows`, модуль `Windows`: `Feature Windows / Add vault picker`.
  В `Dev` не мержить, не пушить без слова Макара.
- Свои задачи веди в разделе «Журнал» внизу этого файла, а не в TASKS.md: так ветки не
  конфликтуют. Даты — в формате `2026-11-01`.

## Сначала — решение Макара

Стек под Windows не выбран. Не начинай код, пока Макар не выберет. Предложи 2–3 варианта коротко
(например: C# + WinUI 3, Swift на Windows + WinUI, Tauri), у каждого — плюсы и минусы для этого
проекта, и свою рекомендацию. Учитывай, что Макар — дизайнер, нативное приложение у него первое;
ему важен вид из его фреймов Figma, плавные анимации и стеклянные слои ([UI.md](UI.md)).
Экраны рисует он: мак-версия — образец, но новый экран или элемент под Windows без его фрейма
не придумывать.

## Что переносится и чем заменить

| На Mac | Что делает | На Windows |
|---|---|---|
| `NotesCore` (Foundation, libgit2) | заметки, задачи, git, синхронизация, шаблоны | логика переписывается или переносится 1:1; тесты `NotesCore/Tests` — образец поведения |
| libgit2 | git без установленного git | libgit2 / LibGit2Sharp |
| Keychain (`TokenStore`, `PinCode`) | токен GitHub, хеш пинкода | Windows Credential Manager / DPAPI. Не в файлах и не в реестре открытым текстом |
| LocalAuthentication | Touch ID | Windows Hello |
| Carbon hotkey | глобальная надиктовка | `RegisterHotKey` |
| AX + CGEvent ⌘V | вставка в поле с курсором | UI Automation + `SendInput` Ctrl+V, только если фокус в текстовом поле |
| EventKit | задачи в Apple Calendar | **решение Макара**: Apple Calendar на Windows нет |
| FoundationModels | «кратко» и задачи из расшифровки | аналога нет. Скрыть функцию и спросить Макара |
| NaturalLanguage (`SemanticIndex`) | поиск по смыслу | нужна замена-модель: спросить, качать только по требованию |
| WhisperKit (CoreML) | распознавание Whisper | whisper.cpp или sherpa-onnx |
| sherpa-onnx (GigaAM, спикеры) | распознавание, кто говорит | sherpa-onnx есть под Windows. Те же модели, ссылки и SHA |
| Metal (`Orb.metal`, `DropZone.metal`) | сфера надиктовки, зона перетаскивания | портировать шейдер (HLSL/Direct2D) по виду с мака |
| FSEvents (`FolderWatcher`) | правки снаружи | `ReadDirectoryChangesW` / `FileSystemWatcher` |
| ServiceManagement | запуск при входе | ключ `Run` текущего пользователя |
| `~/Library/Application Support/<id>/` | модели, индекс, кэш | `%LOCALAPPDATA%\notes\`. В хранилище ничего не класть |

## Формат хранилища (договор с маком)

Подробно — [CONTEXT.md](CONTEXT.md). Самое важное:

- Заметка — обычный `.md`, папки — обычные папки. Свои служебные файлы в хранилище не создавать.
- Задача: `- [ ] текст 📅 yyyy-MM-dd` или `… 📅 yyyy-MM-dd HH:mm`, отметка — `- [x]`.
- Расшифровки — в папке `расшифровки/`, шаблоны — в папке шаблонов из настроек. Плейсхолдеры:
  `{{дата}}`, `{{время}}`, `{{название}}`.
- При конфликте git сохраняются обе версии, ничего не выбрасывается молча.

## Грабли, которых на маке нет

- **Нормализация Юникода.** Мак пишет имена файлов в NFD, Windows — в NFC. «й» и «ё» становятся
  разными строками: дубли файлов, «удалённые» заметки в git. Сравнивай пути после нормализации
  и не переименовывай чужие файлы ради неё.
- **Запрещённые имена.** На Windows нельзя `< > : " / \ | ? *`, имена `CON`, `NUL`, `COM1` и т. п.,
  точку или пробел в конце. С мака такие заметки придут. Не падать, не переименовывать молча:
  показать человеку, какие файлы не открылись.
- **Название `<notes>`** нельзя использовать как имя папки или файла на Windows. Для путей бери `notes`.
- **Перевод строк.** Не превращать LF в CRLF: в репозитории хранилища ставить `core.autocrlf=false`
  локально (только в нём; глобальный конфиг git не трогать). Сохранять файл с теми концами строк,
  с какими он пришёл.
- **Длинные пути** (больше 260 символов) и регистр букв в имени (обе системы его не различают,
  а git различает).
- Кириллица в путях везде: в тестах, логах, путях моделей.

## Проверка

Сделано — значит проверено на Windows: сборка, тесты, снимок окна рядом с кадром мака или Figma.
Если сессия идёт на маке и собрать или запустить под Windows нельзя — так и сказать Макару,
а не «должно работать». Хранилище для проверок — тестовое, не его настоящее.
