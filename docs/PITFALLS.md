# Грабли

Сюда — всё, на что ушло больше получаса: симптом, причина и как правильно.

**SwiftUI / macOS:**

- **Эффект Glass из Figma ≠ системный `.glassEffect`.** Системное стекло размывает фон и рисует свой обод,
  а Glass в Figma увеличивает и сдвигает то, что под ним, и слегка матует. На планках загрузки вместо
  шахматки выходили белые полосы со швами. Такие места рисуем сами (`GlassSlats`: Canvas, свой слой
  на каждую планку, клип по краям, потом размытие), а не системным стеклом.
- **Цвет — только из `Theme`**, не `.black` / `.white`: зашитый цвет не переключается с темой.
  Что в тёмных кадрах остаётся светлым (карточка пинкода, капсула кода), — `.environment(\.colorScheme, .light)`.
- **`-AppleInterfaceStyle Dark` в аргументах запуска на приложение не действует** — для снимков есть свой
  флаг `-appearance dark`.
- **`.hiddenTitleBar` всё равно резервирует 32 pt** под заголовок, и окно выходит выше макета.
  Автор хочет обычную полосу заголовка с `<notes>`, поэтому окно стандартное: сцена 560×440 под полосой.
- **Слои сверяй по JSON узла Figma**, а не по картинке: маски, поворот (`relativeTransform`),
  что лежит поверх чего. По картинке шапку сделали на всю высоту, а в макете она 66 px с маской.
- Скругления углов сцены не нужны: у окна macOS свои углы.
- **`installTap` в macOS 27 устарел.** Новый метод помечен NS_REFINED_FOR_SWIFT, а Swift-обёртки в SDK
  нет: импортёр делает его бросающим с пустым параметром — `try input.__installTap(…, error: ()) { … }`.
- **macOS спрашивает пароль от Связки ключей при каждом запуске.** Запись в Связке помнит сборку,
  которая её создала. Сборки без команды разработчика (ad-hoc) для macOS каждый раз новые, и чужую запись
  она не отдаёт без пароля. Поэтому в проекте стоит Team (Signing & Capabilities), а `TokenStore` один раз
  пересоздаёт старую запись от имени подписанной сборки. Проверка «есть ли пинкод» читает только
  атрибуты (`exists`), а токен читается не на главном потоке: окно macOS не замораживает приложение.
- **С подписью командой терминал не видит контейнер приложения** (`Operation not permitted`): macOS
  защищает данные чужих приложений. WAV для `-dictationTestFile` клади туда через само приложение
  или дай терминалу доступ в настройках — сами настройки за автора не меняем.
- **Колбэк записи звука идёт не с главного потока**, а в проекте всё по умолчанию на главном акторе.
  Класс записи помечен `nonisolated`, данные под замком — иначе падение на проверке изоляции.

- **`TimelineView(.animation)` крутится и у скрытого вида.** Сфера надиктовки живёт в панели всегда,
  и её анимация шла без остановки: «Energy Impact: Very High» в Xcode. Ставь
  `.animation(paused: …)`, когда вида не видно.
- **`.drawingGroup()` ломает материалы.** Слой рисуется отдельно и не видит, что под окном: размытие
  стола (`.ultraThinMaterial`) пропадает. В `drawingGroup` — только своё рисование (кольца), материал — снаружи.

- **Иконка `.icon` собирается руками, но `ictool` не тот.** `/usr/bin/ictool` из Xcode — это actool,
  он не умеет рендерить. Нужный лежит в `Icon Composer.app/Contents/Executables/ictool`
  (`--export-image --platform macOS --rendition Default|Dark`). Тёмный вариант слоя пишется только так:
  `"image-name-specializations": [{"value": "свет.png"}, {"appearance": "dark", "value": "тьма.png"}]` —
  без записи по умолчанию и с отдельным `image-name` тёмная просто не включается.

- **`.clipped()` после `.offset()` обрезает по старому месту.** Лист заметок сдвинут на 279, а обрезка шла
  по 0…906 — правый край с четвёртой папкой пропадал. Сначала `.clipped()`, потом `.offset()`.
- **Отложенное сохранение через отменяемую `Task` не писало файл**: задача отменялась раньше, чем
  успевала записать, и текст сохранялся только при переименовании. Теперь номер правки +
  `asyncAfter`: пишет последняя. Поймала самопроверка `-notesSelfTest`.
- **Bundle id сменился на `makarkabanov`** (вместе с Team): у приложения новый контейнер и свои настройки —
  первый вход и папку хранилища придётся выбрать заново.

- **Проверки на тестовой папке писали в настоящий Календарь Макара.** У приложения был доступ к календарю,
  и задачи из `-testVault` уехали туда событиями (4 штуки, удалены `-calendarCleanup`). Теперь с `-testVault`
  синхронизация календаря выключена. Любая проверка с правами на чужие данные — только на выключенной записи.
- **Связи «задача ↔ событие» не сохранялись**: в новом контейнере не было папки Application Support, запись
  молча падала, и каждый запуск создавал события заново. Папку создаём сами.
- **Бинарник, запущенный из терминала, получает права терминала, а не приложения** — календаря не видит.
  Для проверок с правами: `open -n -F --stderr файл приложение --args …`.
- **В macOS 27 `AVAssetReader.add` и `startReading` устарели**: `reader.outputProvider(for:)`, `try reader.start()`,
  `try await provider.next()`, данные — через `withUnsafeSampleBuffer`.

**Figma через MCP (use_figma):**

- **Цвет из переменной рендерится по «сырому» цвету.** `setBoundVariableForPaint` поверх
  `{color: чёрный}` в редакторе выглядит правильно, а скриншот и экспорт рисуют чёрный (так сайдбар
  стал чёрным). Сырой цвет ставь равным значению переменной.
- **Прозрачность у привязанной заливки теряется.** Сегодняшний день в календаре залился сплошным синим.
  Полупрозрачное делай обычной заливкой с `opacity`, без переменной.
- **`createVector()` создаётся с чёрной обводкой 1px.** Убирай её: `strokes = []`.
- **`resize()` у авто-лейаута ставит FIXED.** Карточка папки схлопнулась до 10px. После `resize`
  заново ставь `primaryAxisSizingMode = 'AUTO'`.
- **Локальные шрифты Figma через MCP не видит**, только свои (Google Fonts, SF Pro).
- **`get_screenshot` не увеличивает**: кадр 284 px отдаётся 284 px при любом `maxDimension`. Для 1024 —
  временная копия кадра, `rescale(1024/284)`, снимок, копию удалить.
- **Проверять надо `get_screenshot`, а не `node.screenshot()`.** Внутренний скриншот рендерит стекло иначе.
- **⌘Z ронял приложение** (30.10.2026): у NSTextView общий с окном стек отмены, после смены заметки
  отмена звала уже закрытый редактор (`_NSUndoStack popAndInvoke` → SIGSEGV). Теперь у каждого редактора
  свой `UndoManager` через `undoManager(for:)`, при смене заметки стек чистится.
- **Длинная надиктовка роняла приложение** (30.10.2026): кодировщик GigaAM бросает исключение C++ на записи
  в минуты, из Swift его не поймать — `abort`. Запись режется на куски до 20 с по тишине
  (`Transcribers.pieces`), до распознавания лежит на диске и после сбоя распознаётся при запуске.
- **Отладочной сборке не прочитать «Загрузки»** через `-dictationTestFile`: в подписи Debug нет
  `downloads.read-only`. Итог теста теперь пишется в stderr (`open --stderr`), там видно и эту причину.
