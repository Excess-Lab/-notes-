# Как устроено приложение

Технический контекст: что из чего сделано и почему. Что и зачем делаем — в [PRODUCT.md](PRODUCT.md).
Пока это **план**, кода почти нет. Когда решение принято и сделано, пометь его как «сделано»
и укажи, в каком файле оно лежит.

Автор раньше делал веб-сервисы, а приложения нет, поэтому рядом с некоторыми решениями стоит
параллель с вебом.

---

## Общая схема

```
Хранилище (папка с .md, git-репо)  ←  источник правды
        │
        ├── Редактор и дерево файлов (SwiftUI)
        ├── Sync: git commit / pull / push в фоне
        ├── Индекс поиска (кэш в Application Support, не в хранилище)
        └── Задачи → EventKit → Apple Calendar

Надиктовка (живёт отдельно от окна):
  глобальный хоткей → плавающая панель → микрофон → Whisper → буфер обмена
```

## Хранилище и доступ к файлам

- Приложение работает в **песочнице** (sandbox) macOS: без разрешения пользователя оно не видит его файлы.
  Доступ к папке хранилища даётся через окно выбора папки и запоминается через
  **security-scoped bookmark**. Веб-аналог: токен доступа к одной папке, который живёт между запусками.
- Изменения, сделанные снаружи (другой редактор, git pull), отслеживаются через FSEvents / `DispatchSource`.

## Git в папке и GitHub

**Решено:** локальный git плюс вход в GitHub по коду. Чужие настройки (`~/.ssh`, глобальный git config) не читаем.

- **Git — libgit2 напрямую через C API** (пакет `ibrahimcetin/libgit2` 1.9.2, собирается из исходников),
  а не системным `git`: на чистом Mac git нет без Command Line Tools. Обёртку SwiftGitX смотрели и не взяли:
  в ней нет init с веткой main и push с токеном. Код — `NotesCore/Sources/NotesCore/GitVault.swift`.
- **Песочница остаётся включённой.** Нужен доступ к выбранной папке (security-scoped bookmark,
  `notes.entitlements`) и исходящая сеть (`ENABLE_OUTGOING_NETWORK_CONNECTIONS`).
- **Токен в git не пишем.** Push передаёт его паролем через колбэк libgit2, в URL remote — чистый адрес.
- **Инициализация:** если `.git` нет — `init`, свой `.gitignore` (`.DS_Store`, корзина, видео/аудио),
  автор `notes <notes@local>` в `.git/config`, первый коммит «начало истории».
  Если папка в iCloud Drive — предупредить: iCloud может сломать `.git`.
- **Автокоммит раз в час** (решение автора: не на каждую паузу в правках). Коммитим всё накопившееся,
  кто бы ни правил — мы, другой редактор, Finder. Подпись по именам и виду правки: «новая: идеи.md»,
  «правки: план.md, идеи.md», «удалена: старое.md», вперемешку — «правки: план.md, +1 новая, −2 удалены».
  Нет изменений — нет коммита. Файлы при этом всегда на диске: между коммитами ничего не теряется.
- **Забрать с другого Мака (pull)** — в том же часовом цикле и сразу при запуске, после своего коммита
  (незакоммиченный текст никогда не попадает под слияние). Здесь ничего не меняли — просто догоняем
  сервер; правили обе стороны — коммит слияния.
- **Конфликты — без потери текста и без маркеров `<<<<<<<` в заметках.** Одну заметку поменяли на двух
  Маках: в файле остаётся версия этого Мака, версия с другого ложится рядом —
  «план (конфликт 2026-10-19).md», при повторе в тот же день «… 2». Удаление против правки —
  побеждает правка. Код — `NotesCore/Sources/NotesCore/GitVault+Pull.swift`.
- **Второй Мак:** вход в GitHub, где `notes` уже с историей, сначала забирает и сливает её, потом
  отправляет — иначе GitHub отклонил бы push.
- **Отправка:** в том же часовом цикле проверяем, прошли ли сутки с прошлой отправки и есть ли неотправленные коммиты.
  Отсчёт — от первой отправки при входе в GitHub. Код — `NotesCore/Sources/NotesCore/Sync.swift`, `SyncController`.
- **Вход — GitHub Device Flow.** Работает без своего сервера и без client secret. Токен — в Keychain.
  Веб-аналог: вход на телевизоре по коду с телефона.
  - Код живёт **15 минут** (`expires_in: 900`, задаёт GitHub) — решили не сокращать. Код протух —
    показываем «код истёк» и «получить новый код».
  - Приложение опрашивает GitHub с интервалом из ответа (обычно 5 с, на `slow_down` +5 с).
  - Ушёл с экрана, нажал «назад» или закрыл окно — опрос останавливаем и забываем `device_code`.
    Тогда код, введённый позже, никому токен не даст.
  - Открыто: **OAuth App или GitHub App.** У OAuth App scope `repo` даёт доступ ко всем приватным
    репозиториям. GitHub App можно ограничить одним `notes` (токен на 8 ч, продлевается сам), но надо
    проверить, может ли он сам создать репозиторий от имени пользователя.
- **Репозиторий `notes` создаётся через GitHub API** (`POST /user/repos`, `private: true`). Если он уже
  есть (ответ 422), подключаемся к нему. Remote `origin` → `https://github.com/<логин>/notes.git`.
- **Push/pull по HTTPS с токеном — раз в день** (так в макете «гитхаб кул (5)»), плюс при запуске.
  Коммиты при этом локальные и частые. Конфликты не должны терять текст.

## Поиск

С 31.10.2026 поиск один на всё (ТЗ Макара): ⌘K находит заметки, задачи, события календаря (год назад и вперёд,
читаются при открытии поиска), видео и слова внутри расшифровок. Совпадение — все слова запроса, без регистра
и ё/е (`SearchQuery`). Выдача группами: заметки, задачи, события, видео. Событие открывает свой день в
календаре, видео — свою расшифровку, задача — заметку, где она записана. Поиск «по смыслу» из приложения
убран; ниже — как он устроен, если вернётся с моделью получше.

## Поиск по смыслу (не подключён)

- Тексты заметок режутся на куски (по абзацам или заголовкам), для каждого куска считается вектор (эмбеддинг).
- Запрос тоже превращается в вектор, ищем ближайшие по косинусной близости.
- Объём личного хранилища — тысячи заметок, поэтому хватает перебора в памяти; отдельная векторная база не нужна.
- Индекс хранится в SQLite в `~/Library/Application Support/…`, а не в хранилище: это кэш, в git ему не место.
  Для каждого файла запоминается хэш, и пересчитываются только изменившиеся файлы.

Кандидаты на модель (цель — маленький размер и нормальный русский):
- **`NLContextualEmbedding` от Apple.** Встроена в macOS и не весит в сборке ничего. Качество поиска нужно проверить.
- **Маленькая открытая модель через Core ML** (например, `multilingual-e5-small`, ~100+ МБ). Скачивается по требованию.

Сначала попробовать встроенную. Если качество на русском плохое, переходить на скачиваемую.

**А может, macOS сделает всё сама?** У Core Spotlight с macOS 15 есть семантический поиск
(`CSSearchableIndex` + `CSUserQuery`): приложение отдаёт заметки в системный индекс, а поиск по смыслу
делает система. Звучит идеально, но на форумах Apple разработчики пишут, что он находит только
буквальные совпадения, а на 26-й версии иногда молча ничего не возвращает (таймаут модели эмбеддингов).
Официального примера Apple так и не выпустила. Поэтому: **отдавать заметки в Spotlight стоит**
(они будут находиться и в системном поиске), но **свой поиск по смыслу строим на своём индексе**.
Перед этапом 4 стоит перепроверить на живом маке.

## Надиктовка

**Сделано** (код — `<notes>/Dictation/`, `NotesSpeech/`):

- **Хоткей ⌥ space, «нажал — нажал»** (решение автора, не удержание): первое нажатие — пишем, второе — распознаём.
  Забыли нажать второй раз — через 5 минут останавливаемся сами. Пока распознаём, нажатия игнорируются.
  Carbon `RegisterEventHotKey` сообщает о нажатии только нашей комбинации; «Универсальный доступ» не нужен.
- **Сфера** — `NSPanel` поверх всех окон и рабочих столов, фокус не забирает, клики пропускает. Внизу по
  центру экрана с курсором. Волны — пять синусоид из компонента Figma, амплитуда от громкости микрофона.
- **Запись:** `AVAudioEngine` → сразу 16 кГц моно Float. Фразы короче 0,4 с — случайное нажатие, не распознаём.
- **Распознавание — локально:**
  - **GigaAM v3 с пунктуацией** через sherpa-onnx 1.13.8 (Apache-2.0, готовая сборка для Apple Silicon,
    ~18 МБ в архиве). Модель — `nemo_transducer`, 64 мел-полосы, ~176 МБ архив / ~230 МБ на диске,
    лицензия MIT. 11 секунд речи — ~1,8 с на распознавание. По умолчанию.
  - **Whisper small / large-v3 turbo** через WhisperKit 1.1.1 (MIT, Core ML). 464 МБ / 1,6 ГБ.
- **Модели** качаются в Application Support контейнера; GigaAM — с проверкой SHA-256 и распаковкой во
  временную папку (недокачанная не выглядит установленной). Загружаются в память один раз.
- **Результат** — в буфер обмена, сфера показывает галочку. Вставляет человек сам.

- **Смена хоткея:** «изменить» на шаге 8 записывает следующее нажатие. Без ⌘, ⌥ или ⌃ не даём (перехватили бы
  обычный набор текста; F-клавиши можно), системные (⌘ space, ⌘Q…) не даём. Если сочетание заняло другое
  приложение, macOS откажет в регистрации — оставляем старое и пишем «занято другим приложением».
  Хранится в UserDefaults (`NotesCore/Sources/NotesCore/HotKeyCombo.swift`).

Не сделано: подсказка на экране, если модель не скачана (сейчас звуковой сигнал).
Облачный SaluteSpeech и системный `SpeechAnalyzer` не берём: нужен аккаунт/закрытая модель.

## Задачи и календарь

- Задачи лежат в Markdown (формат решаем).
- EventKit: нужно разрешение на календарь (Info.plist + entitlement).
- Для каждой задачи запоминается id события в календаре, чтобы при изменении обновлять событие, а не плодить новые.

## Размер приложения

- В сборку не кладём ни одной модели. Whisper и, если понадобится, эмбеддинги скачиваются отдельно, по включению функции.
- Каждую зависимость оцениваем, в том числе по весу.

## Папки расшифровок

- Список папок — `videoFolders` в UserDefaults, у расшифровки поле `folder` в index.json (Application Support).
  В хранилище папка появляется только при «сохранить как заметку»: `расшифровки/<папка>/<название>.md` (31.10.2026).

## Спикеры в расшифровках

- `Diarization` (NotesSpeech): pyannote-сегментация 3.0 + CAM++ из релизов sherpa-onnx, ~35 МБ, качаются по кнопке
  «спикеры в расшифровках» в настройках надиктовки в `models/speakers/`, суммы сверяются. Включено по умолчанию,
  когда скачано (`speakers` в UserDefaults).
- Со спикерами запись берётся в память целиком (разметке нужен весь звук; час — ~230 МБ) и режется не по 20 с, а по
  репликам: реплики одного голоса с паузой < 1,5 с склеиваются, длинные — на куски ≤ 20 с. Так смена голоса посреди
  куска не теряется. Голосов не нашлось — обычные 20 с без спикеров.
- Номера голосов — по порядку появления (`Transcript.assign`), имена — `names` в JSON расшифровки. Правка спикеров
  меняет только JSON; заметку в хранилище не трогаем — её мог править человек (31.10.2026).

## Apple Intelligence

- По желанию, выключено по умолчанию (`intelligence` в UserDefaults). Системная модель Foundation Models, на этом mac,
  в сеть не ходит, в сборке ничего не добавляет. Окно ~4096 токенов: текст режется по предложениям на куски ≤ 5000
  знаков, каждый сжимается, потом сжатые части — ещё раз в одно.
- В инструкции не перечислять рубрики («решения, задачи, цифры»): на коротком тексте модель отвечала этими словами (31.10.2026).
- «Кратко» — только для заметок (искра в шапке): у расшифровок Макар его убрал 31.10.2026.
- Задачи из расшифровки — guided generation (`@Generable`): модель отвечает структурой. Даты она считать не умеет
  («завтра» становилось сегодня), поэтому в инструкции — готовый список ближайших 8 дней с днями недели (31.10.2026).
