## Статусы

Каждая задача — пункт списка, который начинается со статуса в квадратных скобках.
`DocsTests` падает на пункте без статуса или с чужим словом.

| Статус | Значит |
|---|---|
| `[в работе]` | делается сейчас; одна-две задачи, не больше |
| `[следующая]` | берётся, как только освободятся руки; порядок — сверху вниз |
| `[ждёт Макара]` | дальше решение Макара; в строке — вопрос и рекомендация |

| `[готово]` | сделано и проверено; в строке — коммит. Убирается после релиза |

Формат строки: статус, **что**, где лежит, состояние, следующий шаг.
