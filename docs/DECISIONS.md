# Решения Макара

Принятые решения. Не переспрашивать и не переигрывать молча: если кажется, что решение устарело,
сказать Макару с причиной. Новое — сюда, с датой и, где можно, его словами. Что за продукт —
[PRODUCT.md](PRODUCT.md), как устроен — [CONTEXT.md](CONTEXT.md).

## Продукт

- Только macOS, open source, для себя. Без аккаунтов и своего сервера (10.2026).
- **Канбана нет**: «канбан не нужен» (10.2026).
- Заметки — обычные `.md` файлы; хранилище открывается любым другим редактором. Obsidian нигде не
  упоминаем — ни в доках, ни в коде, ни в `.gitignore` хранилища (19.10.2026).
- Поиск — по смыслу, через эмбеддинги, локально; приложение должно оставаться лёгким (10.2026).
- Тёмная тема — по кадрам Макара, следует теме системы: «вот пример темной темы все подстрой» (26.10.2026).
- Окно фиксированного размера, без ресайза: «ресайзинг впизду» (10.2026).

## Главный экран

- Собираем по кадрам секции «Заметки»: «собери на основе моего интерфейса» (26.10.2026).
- На карточках папок наклеек нет, название под карточкой — xWd xBd 15, «новая папка» так же (26.10.2026).
- Разделы задач, календаря и видео и «по смыслу» в поиске приглушены, пока не сделаны.

## Задачи

- Задача — строка Markdown в любой заметке: `- [ ] Созвониться 📅 2026-10-16 15:00`, готово — `- [x]`.
  Дата и время необязательны. Формат выбрал агент (26.10.2026) — обычный чекбокс читается любым редактором;
  поменять можно, пока задач мало.
- Задача с датой попадает в выбранный календарь Apple; отметили готовой — событие убирается.
  Связка «задача ↔ событие» хранится вне хранилища (Application Support), заметки не трогаем.

## Git и GitHub

- Коммит в хранилище — **раз в час**, а не на каждую паузу: «каждый 1 час давай хотя бы» (10.2026).
- Отправка на GitHub — раз в сутки; репозиторий `notes` приватный, создаётся сам (10.2026).
- Вход в GitHub — по коду (Device Flow), код живёт 15 минут, как задаёт GitHub: «ладно 15 оставим» (10.2026).
- Конфликты не теряют текст: обе версии рядом, правка сильнее удаления (10.2026).

## Надиктовка

- Текст — в буфер обмена, вставляет человек сам (10.2026).
- Хоткей — **переключатель**, не удержание: «как нажал — запустилось и обратно» (19.10.2026).
- Модели — все три на выбор, по умолчанию GigaAM v3 (10.2026).
- Нет модели — приложение предлагает скачать, показывает уже скачанные, после ответа возвращает туда,
  откуда пришли; не ходит по кругу (19.10.2026). Свой дизайн этого окна Макар нарисует потом,
  пока — системное окно.

## Вход и пинкод

- Пинкод закрывает **вход в приложение**, заметки не шифруются — иначе их не откроет другой редактор (10.2026).
- Окно пинкода и «забыл пинкод» — «сам сделай в той же стилистике» (19.10.2026), согласовано по кадрам
  9.1–9.3, 11–11.2.
- Умный вход (19.10.2026, «канеш делаем»): не на каждом запуске; блокировка и сон Mac закрывают сразу;
  15 минут в фоне — спросить снова; перезапуск в течение 5 минут — без пинкода; после 5 ошибок пауза
  30 с с ростом до 15 минут; «забыл пинкод» — паролем от Mac; надиктовка от входа не зависит.

## Поиск

- Поиск по смыслу — **бета**, включается в настройках → поиск, по умолчанию выключен: «дай его включить и пометь значком бета» (30.10.2026). Когда включён — поиск смесь по смыслу (встроенная модель Apple, `NLContextualEmbedding`) и по словам: «3 из 4 норм,
  просто делаем микс» (30.10.2026). Где совпали слова — выше, дальше похожие по смыслу. Индекс в Application
  Support, пересчёт только изменённых. Скачиваемая e5 отложена: пакет swift-embeddings не подключали.

## Видео

- Готовая расшифровка сама ложится в хранилище: `расшифровки/<имя>.md` с frontmatter — источник, когда
  загружено, длительность, модель, слов; дни загрузки видны в календаре приложения (27.10.2026).
- Если на GitHub уже есть `notes`, вход подключается к нему и забирает историю, новый не создаёт (так и было).

## Сборка и процесс

- «делай как считаешь нужным я те доверяю» (27.10.2026): лицензия — MIT (файл LICENSE); вход в GitHub —
  OAuth App как есть, GitHub App с доступом к одному `notes` проверить перед релизом. Пуш — по-прежнему
  только по прямому слову.
- Bundle id остаётся `makarkabanov`: «бандл оставь» (27.10.2026).

- Коммиты — **без вопроса**, когда работа проверена; пуш — только по слову (до 19.10.2026).
- Подпись сборки — Personal Team Макара (U8T962NCZ2), чтобы Связка ключей не спрашивала пароль (19.10.2026).
- Иконка приложения — потом: «иконка приложения, okay не» (19.10.2026).
- Подход к работе и документации — как в «Единстве»: маршрутизатор CLAUDE.md, файлы областей,
  журнал задач, решения, карта и тест-сторож (26.10.2026).
- Поиск — один по сущностям: заметки, задачи, события, видео, расшифровки; «по смыслу (бета)» и «по тексту» убраны: «Убрать… один поиск находит заметки, задачи, события, видео» (ТЗ, 30.10.2026).
- В шапке задачи, календарь, видео, настройки; заметки — по логотипу (кадр 152:32854; настройки вернули: «настройки пропали», 31.10.2026).
- Windows — только обсуждать, не делать: «с виндой надо обсуждать» (31.10.2026).
- Экран задач показывает то же, что уходит в календарь: задачи из папок, включённых в настройках («задачи из папок»); остальной Markdown не тянем: «отображаем то, что с календаря и даём настроить, что тянуть с маркдаунов» (ТЗ, 30.10.2026).
- Шапка: разделы со словами важнее синхронизации, но синхронизация не пропадает — сжимается до значка и стоит у правого края: «почему синхронизация пропадает», «к леву прилипает», «гибрид, только иконки, но выбранное показывает текст — только когда можем показать текст каждого раздела» (31.10.2026).
- «Как у Apple» в календаре — про удобство, а не про вид: перетаскивание, растягивание, линия «сейчас», карточка события и т. п. (31.10.2026).
- Папки для расшифровок видео — на моё усмотрение: «как угодно» (31.10.2026).
- Настройки — «прям подробные… чтобы всё досконально» (31.10.2026).
- Спикеры в расшифровках делаем, с переименованием и переотметкой реплик при ошибке распознавания: «спикеры, конечно, делаем» (31.10.2026). Новая зависимость не нужна — sherpa-onnx уже в сборке; модели качаются по требованию.
- Apple Intelligence — интеграция через API как дополнительная функция, включается в настройках (31.10.2026).
- Windows — после всего остального дать варианты на обсуждение (31.10.2026).
- Релиз 1.0.0 на GitHub — делаем сейчас, «пока не делай релиз» снято: «сразу сделаем … в мэйн дроп релиза 1
  типа <notes> 1.0.0 и описание на англйиском в названии описаний нет» (01.11.2026). Название релиза —
  только имя и версия, описание — по-английски, из CHANGELOG ([GIT.md](GIT.md)).
